# UI Navigation Update

- The Play tab is the game carousel.
- Practice is no longer a bottom-navigation tab; it opens as a game route from the carousel or results.
- Bottom navigation is now Play, Compete, Leaderboard, Stats.
- Daily Challenge is a full page with a visible back and exit control.
- Full-screen quiz routes use the Play tab's banner-visibility slot.
- No Supabase changes are required for this UI/navigation update.
